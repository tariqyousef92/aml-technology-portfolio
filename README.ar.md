# ملف أعمال تقنيات مكافحة غسل الأموال (AML)

> 🇬🇧 English version: [README.md](README.md)

## نبذة عني
أنا مختص في مكافحة غسل الأموال بخبرة [X] سنوات في مجال [مراقبة العمليات / اعرف عميلك والعناية الواجبة / فحص العقوبات / التحقيقات] لدى [بنك / شركة تقنية مالية / مؤسسة مالية].
أعمل حالياً على تطوير مهاراتي التقنية في Python وSQL وتحليل البيانات، بهدف أتمتة عمليات مكافحة غسل الأموال وتحسين كشف الجرائم المالية.

## الهدف
يعرض هذا الملف كيف أوظّف البيانات والتقنية لحل مشكلات حقيقية في مكافحة غسل الأموال، مثل بناء منطق الكشف، وتحليل أنماط العمليات، وتقليل التنبيهات الخاطئة (False Positives).
هدفي الانتقال إلى دور في تقنيات مكافحة غسل الأموال أو تحليلات الجرائم المالية، أجمع فيه بين الخبرة في المجال والحلول التقنية.

## المشاريع المخطط لها

### 1. محرك مراقبة العمليات المبني على القواعد
محرك مبني بـ Python وSQL يطبّق سيناريوهات مكافحة غسل الأموال التقليدية على بيانات العمليات، مثل تجزئة المبالغ (Structuring)، والحركة السريعة للأموال، والدول عالية المخاطر، والنشاط النقدي غير الاعتيادي. يولّد المحرك تنبيهات مع درجة مخاطر لكل تنبيه.
**المهارات:** Python، Pandas، SQL، تصميم السيناريوهات، ضبط الحدود (Thresholds)

### 2. أداة فحص الأسماء على قوائم العقوبات والأشخاص المعرّضين سياسياً (PEP)
أداة تطابق أسماء العملاء مع قوائم العقوبات باستخدام المطابقة التقريبية (Levenshtein وJaro-Winkler)، مع معالجة اختلاف كتابة الأسماء العربية بالأحرف اللاتينية، لتحقيق توازن بين دقة الكشف وتقليل التنبيهات الخاطئة.
**المهارات:** Python، RapidFuzz، تنظيف البيانات، منطق المطابقة

### 3. نموذج تقييم مخاطر العملاء (KYC/CDD)
نموذج يقيّم مخاطر العملاء بناءً على عوامل مثل المهنة، والموقع الجغرافي، والمنتجات المستخدمة، وسلوك العمليات، ويصنّفهم إلى مخاطر منخفضة / متوسطة / عالية.
**المهارات:** Python، هندسة الخصائص (Feature Engineering)، منهجية تقييم المخاطر، التصوير البياني للبيانات

### 4. كشف الأنماط الشاذة باستخدام تعلّم الآلة
نماذج تعلّم غير موجَّه (Isolation Forest والتجميع Clustering) لكشف السلوك غير الاعتيادي في العمليات الذي قد لا تلتقطه الأنظمة المبنية على القواعد، مع مقارنة النتائج بمحرك القواعد في المشروع الأول.
**المهارات:** scikit-learn، تقييم النماذج، قابلية تفسير النتائج

### 5. تحليل الشبكات لكشف حسابات "البغال المالية" (Money Mules)
تحليل شبكي لتدفق الأموال بين الحسابات لاكتشاف الشبكات المشبوهة، والعمليات الدائرية، والحسابات المحتمل استخدامها كوسيط لتمرير الأموال.
**المهارات:** NetworkX، تحليل الشبكات، التصوير البياني

## إخلاء مسؤولية
جميع البيانات المستخدمة في هذا الملف **اصطناعية (Synthetic)** وتم إنشاؤها لأغراض تعليمية وتوضيحية فقط، ولا تتضمن أي بيانات حقيقية لعملاء أو عمليات أو مؤسسات.

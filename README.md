## Planned Projects

### 1. Rule-Based Transaction Monitoring Engine
A Python/SQL engine that applies classic AML scenarios to transaction data: structuring, rapid movement of funds, high-risk jurisdictions and unusual cash activity. It generates alerts with risk scores.
**Skills:** Python, Pandas, SQL, scenario design, threshold tuning

### 2. Sanctions & PEP Name Screening Tool
A screening tool that matches customer names against sanctions lists, using fuzzy matching (Levenshtein, Jaro-Winkler) and transliteration handling for Arabic names, to balance hit rate and false positives.
**Skills:** Python, RapidFuzz, data cleaning, matching logic

### 3. Customer Risk Scoring Model (KYC/CDD)
A risk-rating model that scores customers on factors such as occupation, geography, product usage and transaction behavior, and classifies them as Low / Medium / High risk.
**Skills:** Python, feature engineering, risk methodology, visualization

### 4. Anomaly Detection with Machine Learning
Unsupervised models (Isolation Forest, clustering) that flag unusual transaction behavior that rule-based systems may miss. Results are compared against the rules engine from Project 1.
**Skills:** scikit-learn, model evaluation, explainability

### 5. Network Analysis for Money Mule Detection
A graph analysis of fund flows between accounts that identifies suspicious networks, circular transactions and possible mule accounts.
**Skills:** NetworkX, graph analytics, visualization

## Disclaimer
